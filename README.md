# Portfolio

Ma Jing Ming 的个人作品集网站 —— 纯静态 HTML/CSS/JS，浅色极简风格，响应式适配。

## 目录结构

```
portfolio/
├── index.html          # 首页（Hero + 四个项目卡片）
├── project-1.html      # 项目一：店铺装修 Agent
├── project-2.html      # 项目二：闪购管家
├── project-3.html      # 项目三：系列图工具
├── project-4.html      # 项目四：店铺装修 Skill
├── assets/
│   ├── hero.png        # 首页主图
│   ├── cover-1~4.png   # 四个项目卡片封面图
│   └── projects/       # 各项目详情页配图（X-Y.png）
└── README.md
```

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 部署到 GitHub Pages

1. 推送到 GitHub 仓库
2. Settings → Pages → Branch 选 `main` → Save
3. 访问 `https://<用户名>.github.io/portfolio/`
